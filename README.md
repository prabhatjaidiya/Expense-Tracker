# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/expense-tracker.git
```

Move into project

```bash
cd expense-tracker
```

Install packages

```bash
npm install
```

Run locally

```bash
npm run dev
```

Production build

```bash
npm run build
```

Preview build

```bash
npm run preview
```
